# Project Management Frontend

Vue 3 + Vite frontend for the project management system.

## Setup

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## API configuration

Create a local `.env` file when the backend ports differ from the defaults:

```env
VITE_PROJECT_API=http://localhost:5047/api
VITE_TASK_API=http://localhost:5217/api
VITE_NOTIFY_API=http://localhost:5177/api
```
